# Medical Report Quality Guidelines

## Required sections / Обязательные разделы

A complete medical report should include:
Полное медицинское заключение должно включать:

1. Patient complaints / Жалобы пациента
2. Medical history / Анамнез
3. Objective findings / Объективный осмотр
4. Diagnosis / Диагноз
5. Treatment plan / План лечения
6. Recommendations / Рекомендации
7. Follow-up plan / План наблюдения или контроль

## Safety checks / Проверка безопасности

A medical report should mention:
В заключении желательно указать:

- Allergies / Аллергии
- Contraindications / Противопоказания
- Red flags / Красные флаги
- Follow-up instructions / Инструкции по наблюдению

## Quality criteria / Критерии качества

A high-quality medical report should be structured, complete, clinically clear and actionable.

Качественное медицинское заключение должно быть структурированным, полным, клинически понятным и применимым на практике.

The report should avoid vague recommendations and should clearly describe what the patient should do next.

Заключение не должно содержать расплывчатых рекомендаций и должно ясно описывать следующие действия пациента.
